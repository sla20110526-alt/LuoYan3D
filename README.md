# 《沙棘之恋》裸眼 3D 项目

本仓库保存当前项目目录中的原始素材、1:1 视频、分镜／Prompt、Blender 双屏回投工程、测试输出及制作记录。仓库中的测试输出不等于客户最终上屏文件。

回家继续工作请先读 [项目接续记忆_2026-10-01.md](项目接续记忆_2026-10-01.md)。当前有效制作文件是 [分镜锚点 v006](storyboard/沙棘之恋_15秒裸眼3D_分镜锚点_v006.md) 和 [Seedance 2.0 正式 Prompt v006](storyboard/沙棘之恋_SC01-SH001_Seedance2.0_正式Prompt_v006.md)。资产身份及版本见 [资产登记索引](资产登记索引_2026-09-28.md)。

大图、视频、压缩包和 `.blend` 工程由 Git LFS 保存。新电脑克隆后运行 `git lfs install`、`git lfs pull`，再检查所需视频与工程是否完整。部分旧工程／脚本含原电脑的 `D:` 盘绝对路径，换电脑后须在 Blender 中重连素材并复核贴图。项目资料在公开仓库中，后续不要把凭据或其他项目内容放入此目录。
